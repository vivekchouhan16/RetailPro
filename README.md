# 🛍️ RetailPro – Billing & Inventory Management System

> A modern full-stack Retail Management System built with **React.js**, **Spring Boot**, and **MySQL** that streamlines inventory management, billing, and role-based administration.

---

# 🚀 Features

### 🔐 Authentication & Authorization
- JWT-based Authentication
- Spring Security Integration
- Role-Based Access Control (Admin & Staff)
- Protected Frontend Routes

### 📦 Inventory Management
- Product CRUD Operations
- Category Management
- Product Search & Filtering
- Low Stock Monitoring
- Real-Time Inventory Updates

### 🛒 POS Billing System
- Fast Point of Sale (POS) Billing
- Automated Invoice Generation
- Transactional Stock Deduction
- Invoice History Management

### 📊 Dashboard & Analytics
- Responsive Admin Dashboard
- Inventory Overview
- Sales Analytics
- Reusable UI Components

### 🔗 API Integration
- RESTful APIs using Spring Boot
- Axios-based Frontend Communication
- Spring Data JPA for Database Operations

---

### Backend
